# 末日黎明 · Last Dawn

浏览器回合制战术卡牌游戏，双方各操控两名角色。当前包含34名角色、204项角色技能，支持游客大厅、双人联机、贪心策略人机对战、角色轮选、结算回放及断线重连。

## 本地运行

需要 Node.js 22.12 或更新版本，以及支持 WebSocket 的现代浏览器。在项目根目录执行：

```sh
npm ci
npm run dev
```

打开 http://localhost:3000 。Windows PowerShell 若限制运行 npm 脚本，可将命令中的 `npm` 替换为 `npm.cmd`。

本机双人测试可使用普通窗口和无痕窗口，或两种浏览器。游客令牌保存在 sessionStorage；直接复制标签页可能复制令牌，导致新连接接管旧连接。

## 构建后运行

```sh
npm ci
npm run build
npm start
```

客户端构建产物位于 `dist/`。服务端通过自带加载器读取 TypeScript，因此安装时需要保留 devDependencies。

可使用 `npm run check` 检查 TypeScript，使用 `npm run build` 验证构建。测试、E2E、数据提取及模拟命令依赖的部分文件仅保留在本地开发环境，不随公开仓库上传。

## 联机与模式

1. 创建房间并选择模式，另一位玩家从大厅或通过房间号加入；默认快速模式。也可在“人机对战”中与贪心策略电脑对战，电脑方随机选择角色。
2. 双方准备后轮选角色，次序为 A 选1名、B 选2名、A 再选1名。
3. 快速模式跳过技能与通用特性配置，携带全部六个角色技能及“撞击”“蓄力”；角色专属特性仍生效。
4. 对决模式为每名角色从六个技能中选择四个（含被动），并选择通用特性；绑定专属特性的角色固定携带自己的专属特性。
5. 每回合为能够行动的己方存活角色选择技能与目标，提交后按优先级与速度结算。部分效果会触发15秒即时响应窗口。
6. 选目标时预览克制与弱化，结算记录可展开查看伤害明细。每位玩家可独立切换1倍或2倍播放速度。

对局结束后可主动返回大厅；房间在结束90秒或双方均离开后销毁。房间与游客会话暂存于单进程内存，重启服务会清空。当前无账号登录、自动匹配或战绩数据库。

同一局域网中的其他设备可访问运行电脑的局域网 IP 和3000端口，所有玩家需要连接同一服务。客户端使用同源 `/ws`，在 HTTPS 下自动使用 WSS。完整联机游戏需要 Node.js 服务端，不能仅用 GitHub Pages 运行。

## 配置

| 环境变量 | 默认值 | 作用 |
| --- | --- | --- |
| `PORT` | `3000` | HTTP 与 WebSocket 共用端口 |
| `HOST` | `0.0.0.0` | 服务监听地址 |
| `TURN_TIMER_ENABLED` | 默认关闭 | 设置为 `true` 时新房间默认开启常规行动计时；房主可在准备阶段切换 |

PowerShell 示例：

```powershell
$env:PORT='3001'
npm.cmd run dev
```

## 项目目录与正式文档

- `src/`：页面、共享战斗规则、角色数据与人机策略。
- `server/`：HTTP、WebSocket、房间管理与人机工作线程。
- `public/`：网站图标等静态资源。
- `assets/images/characters/manifest.json` 与 `web/`：角色形态清单及网页 WebP 插画。
- `scripts/dev.mjs`、`register.mjs`、`loader.mjs`：服务入口与 TypeScript 加载器。
- [游戏机制与底层逻辑](handoff/02-游戏机制与底层逻辑.md)、[角色设定](handoff/03-角色设定.md)、[全局配置表](handoff/04-全局配置表.md)：正式设计文档。
- [GitHub仓库维护](docs/github-upload.md)：在当前目录检查、提交与推送的步骤。

运行数据以 `src/data/` 为入口，游戏内也提供战斗指南。网页使用正式角色插画，多形态角色在对局中随形态切换图片。

仓库直接使用当前开发目录，通过 `.gitignore` 排除测试、草稿、原始素材、日志、密钥及本地配置。后续修改无需复制到其他目录，仅在作者明确要求更新 GitHub 时提交、推送。
